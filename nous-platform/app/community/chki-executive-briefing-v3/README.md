# CHKI Executive Briefing Portal

## Run locally
Open `index.html` in a browser.

## Personalised views
Use these query parameters:

- General: `index.html`
- Cure Day Hospitals: `index.html?partner=cureday`
- Nitefalls Medical: `index.html?partner=nitefalls`
- Observatory Library: `index.html?partner=observatory`

## Deploy
Upload this folder to your website or place it inside your existing project, for example:

`/chki/index.html`

Then use:

- `/chki/?partner=cureday`
- `/chki/?partner=nitefalls`
- `/chki/?partner=observatory`
